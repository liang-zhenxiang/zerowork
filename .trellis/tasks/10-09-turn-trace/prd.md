# PRD：工作轨迹（Turn Trace）

## 背景

ZeroWork 的核心卖点是「它会把事情做完」——一轮回答里 Agent 可能读了 3 个文件、
改了 2 个、跑了 1 条命令、交付了 1 份产物。但现状是这些动作只能以**逐条折叠行**
的形式看（`tool-head`），跑得越久列表越长：

- **长任务没有全貌**：想知道「这一轮到底做了几件事、有没有失败」，要么数折叠行，
  要么滚动翻找；把「过程」折叠起来后又什么都看不见了。
- **失败/被拦不显眼**：某一步被沙箱拦下或出错时，藏在中间某一行里。
- **与「可审计」的产品身份不匹配**：审计日志在诊断里，但对话本身没有「工作概览」层。

竞品调研（2026-10）：「会话回放 / 执行历史 / watch AI work」是桌面 Agent 应用的
 trending 形态（Devin 的 session recording、Codex 的 Record & Replay、各类 agent
 dashboard），但它们要么是独立工具、要么是网页端时间轴日志。**没有人把它做成
「回合内的动作轨道」**——与折叠工具行互补、点击可定位、折叠过程时依然可见。

## 期望

每个 assistant 回合（turn）新增一条**水平动作轨迹条**，把该回合的工具调用
按发生顺序聚合成可视化节点。

### 功能验收标准

- [ ] **聚合**：相邻同类工具调用合并为一个节点（段），节点显示类别图标 + 类别名 + 计数（>1 时）。类别至少覆盖：读文件、写/改文件、命令、搜索、交付产物、子代理、其他
- [ ] **状态可视**：段内全部成功 = 中性色；含失败/被拦 = 状态色标记（不看颜色也读得出：有 ⚠ 形态与文字提示）；回合进行中，最后一段显示「进行中」脉冲
- [ ] **实时生长**：回合流式进行中，新工具调用实时追加为节点；工具行流式的既有行为不受影响
- [ ] **点击定位**：点击节点 → 滚动到对应工具行、短暂高亮、并展开该行详情（若可展开）。若目标行处于折叠组（tool-group / turn-folded）内，先展开所在组再定位
- [ ] **折叠时仍可见**：把回合「过程」折叠后，轨迹条依然完整显示——它是折叠态下的工作全貌
- [ ] **不出场条件**：回合内没有任何工具调用时不渲染轨迹条；纯文本回答零变化
- [ ] **主题**：亮 / 暗两套同构，全部走 `app.css` token，静态检查（check-theme-tokens）过
- [ ] **可诊断**：节点 title（原生 tooltip）列出该段每个调用的摘要，不猜

### 非目标（本轮不做）

- 不做回合级 / 会话级的跨回合总时间轴（TurnNav 已有轮次导航）
- 不做轨迹条的设置开关（先看真实使用反馈；若有人反馈噪音再加偏好项）
- 不改主进程 / IPC / ledger——纯渲染层聚合
- 不改工具行本身的渲染

## 质量门槛（全部自动化）

- [ ] 单元测试：`trace-core.js` 纯函数全分支（分类 / 合并 / 状态聚合 / 空输入 / 未知工具 / 顺序）
- [ ] e2e GUI 测试：mock 模型多轮工具调用（沿用 widget-render.mjs 的 mock 模式），真实启动
      断言：轨迹条出现、节点数与类别正确、点击定位生效、失败节点可见；
      浅/深主题截图 + 像素断言（非纯色、有内容）
- [ ] `npm run lint:all`、`npm test`、`npm run test:gui` 全绿
- [ ] UI/UX 评审：派资深 UI/UX 设计师 subagent 看截图与实现评审，按意见迭代

## 入手位置

- 新模块：`src/renderer/src/trace-core.js`（纯函数：entries → 轨迹视图模型）
- 渲染：`src/renderer/src/app.js`——`turn-group` 内、`TurnHeader` 之后插 `TurnTraceBar`；
  复用 `toolIconOf` 的图标映射与 `normalizeName`
- 样式：`src/renderer/src/app.css`（token 纪律、双主题同构）
- 测试：`tests/unit/trace-core.test.mjs`、`tests/e2e/turn-trace.mjs`
- 文档：`docs/USAGE.md`（助理一节）、`CHANGELOG.md` `[Unreleased]`

## 难度

中高。难点不在逻辑（聚合是纯函数），在**嵌入一个 68k 行的既有渲染流**而不破坏
流式/折叠/滚动锚定三条既有路径，以及把视觉做到精品档。
