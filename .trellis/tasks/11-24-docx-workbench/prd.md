# PRD：工作台展示与接受 docx 修订（#482）

## 背景

#481 能生成 `kind:"docx"` 待审建议，但工作台只认逐段文本 hunk：docx 建议会显示成空白/错误，也没有接受通道。用户看不到「哪段文字会被换掉」。

## 目标

1. 工作台按 `kind` 分支：docx 建议显示文件、替换前/后文字、目标部件与 v1 边界说明；
   不显示逐段勾选框（v1 只有一次替换）。
2. 接受：IPC 先 ensure docx 运行时，再 `applyDocxProposal`（哈希守卫 → 二进制版本 →
   引擎原子修补 → 审计），成功后 toast 说明「已替换 1 处文字」。
3. 过期时禁用接受并给重新生成指引；拒绝整条不碰文件；左侧列表对 docx 显示「1 处替换」。
4. 旧文本建议的行为完全不变。

## 非目标

- 多段 docx 替换、页眉页脚路由、Word 原生修订痕迹（v1 拒绝）。
- 完整 e2e 与 USAGE（#483）。

## 验收

- [ ] docx 建议在待修订队列中可选，右区显示旧→新与 part；无勾选框
- [ ] 接受后文件正文被替换、建议消失、toast 正确；版本可还原
- [ ] 过期（文件字节变了/文件不在）接受禁用并说明
- [ ] 拒绝只丢弃建议，不改文件
- [ ] 文本建议的现有 e2e/单测全绿
