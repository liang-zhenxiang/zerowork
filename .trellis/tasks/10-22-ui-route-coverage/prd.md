# PRD：UI 覆盖收口（画布光照方向 + 二级页面全路由回归）

## 背景

v0.11.0 把首页、侧栏、设置页、会话页统一到了「极光墨」，但那只是**四个屏**。
下面这些页面同样挂在同一个 `.app` 外壳上，会跟着 token 一起变，却**没有任何像素级
断言守着** —— 一旦某个页面自己写死了颜色或圆角，最坏情况是「点进去掉回旧世界」，
而且只有人肉点才发现：

项目 / 专家·技能·连接器 / 自动化 / 资料库 / 文件历史 / 会话检索 / 诊断 / 统计。

另外设计师提了一个没做完的观察：**页面越往上越亮、越往下越暗**（光照方向一致）。
当前极光重心在标题上方，但页脚那条仍然偏亮，纵向明度不单调。

## 期望

- [ ] 画布在**纵向**上有一条单调的明度衰减：顶部干净、底部收暗，两个主题都要
- [ ] 新增 GUI 测试 `route-crawl`：逐个进入二级页面，截图 + 断言外壳 token 生效
      （不是纯白、圆角一致、背景带极光层），产物进 `artifacts/route-crawl/`
- [ ] 迭代看这些截图，把确实掉队的页面修到同一套语言里
- [ ] 全部断言进 `test:gui` 链，本地全量跑绿

## 不做什么

- 不重做二级页面的信息架构（那是功能改动，不是视觉收口）
- 不为「好看」给二级页面加新的装饰元素；这轮只要求**与首页同一套表面**。

## 验收

- `npm run test:gui:route-crawl` 通过，且 9 个视图截图都能看出是同一套设计语言
- `npm test` / `npm run lint:all` 全绿
