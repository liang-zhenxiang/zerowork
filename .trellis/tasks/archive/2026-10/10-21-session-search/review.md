# 界面评审：会话检索页

评审者：独立 UI/UX 设计师（fresh context，只读；输入是 e2e 真实启动的浅色/深色截图与代码）。
结论原话：**需小修** —— 流程与结构立得住，3 个 P0 是「一眼/一用就会撞上」的问题。

## P0（本轮已全部修）

| # | 问题 | 修法 |
| --- | --- | --- |
| P0-1 | 搜索框双焦点环：外层 `--primary` 边框 + 内层全局 `input:focus-visible` 方框 | 环只画在外层，用 `--text-secondary`（与全局同色）；`.ss-input:focus-visible` 同特异性撤掉 |
| P0-2 | `--text-faint` 被当正文色（角色列 2.1:1） | 角色/提示/会话 meta/「另有 N 处」全部升到 `--text-secondary`；faint 只留图标 |
| P0-3 | hover 顺带改掉 Enter 的目标 | 删 `onMouseEnter`；选中态 `--bg-raised` + 左条，hover 只留底；补 `aria-current` |

## P1（本轮已修，可核对的都改了）

- 命中行箭头常显（不再只在 hover/选中时出现），hover 升色 + 位移 2px。
- 结果卡改内容卡口径：`--bg` 底 + `--radius-md` + 边框；`--bg-raised` 只表示选中行。
- 初始态去掉虚线框（全站虚线框只属于「虚位待建」），与共享 `EmptyState` 同一语言。
- 侧栏换 `IconChatSearch`（气泡 + 放大镜），与顶部「搜索或跳转 ⌘K」的放大镜分开；
  命令面板里同一功能统一叫「会话检索」。
- 键盘提示只在有结果时出现；范围口径统一到「最近 200 个会话」；无结果文案改成
  「只检索最近 200 个会话」；「另有 N 处」不再承诺聊天页有查找条。
- 新增 `capped`：命中会话数到了 limit 时摘要说「只列出前 N 个会话」，
  不再把「显示上限」误报成「扫描上限」（P1-7 的实质问题）。
- 骨架 `role=status` + 读屏文案；骨架行与真行同一网格（结果到达时不右跳 52px）。
- mark 底提到 26% 并补下划线（第二线索不依赖颜色）。

## 未采纳 / 留到后续

- 角色列要过 AA 4.5:1 只能用 `--text`（全站 `--text-secondary` 3.95:1 的系统性欠账）。
  本页保持与全站同档，把「全站次文对比度」作为独立问题处理，不在这里单独破例。
- 完整的 listbox / `aria-activedescendant` 语义：本轮用按钮 + `aria-current`，
  键盘可用；升级成 combobox 需要跨组件的焦点管理，另开任务。

## 评审之外发现并修掉的测试缺陷

深色截图曾在主题切换的 `--dur-fast` 背景过渡中间截屏，拍到「浅色选中底 + 深色文字」
的中间帧，看起来像渲染坏了。e2e 改为等选中行底色真的落到 `rgb(38, 38, 42)` 再截。
