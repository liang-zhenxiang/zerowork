# 设计评审与改进提案（B 部分：界面精品化）

> 评审人视角：桌面工具产品设计师（对标 Linear / Raycast 的克制工具美学 + Apple HIG）。
> 评审依据：真实截图（浅色首页 `artifacts/smoke/home.png`、深色首页/设置
> `artifacts/theme/`、会话视图 `artifacts/widget/final-reply.png`）+
> `docs/DESIGN.md` 全部纪律条款 + 同类产品调研（2026-10：Claude Desktop /
> Cherry Studio / Chatbox）。
> 深色主题（A 部分）已落地，本评审针对其后的精品化。

## A. 现状诊断（按区域，具体到用户感受）

### 首页（浅色截图）
1. **视觉层级平**：标题「今天想完成什么？」、三步清单、能力胶囊全在黑白灰里，
   没有任何一个元素在 0.5 秒内抓住视线。用户感受：「一个干净的表单，不是一个产品」。
   品牌绿 `--brand #00c29a` 只活在侧栏底部一枚状态点——花了logo成本建立的品牌色
   在第一屏几乎零存在感。
2. **三步清单的可点性不可读**：清单项hover 才有反馈，静态状态下与正文行难以区分
   「这是清单还是按钮」。用户感受：上手引导的点击率直接被这种模糊吃掉。
3. **能力胶囊一排 8 个等宽等重**：没有主次，扫读时是一堵字墙。同类做法是
   「常用 4 个显式 + 其余收进『更多』」，或按用户历史使用频率动态排序。
4. **打字机动效的副标题**：动效本身精致，但它是页面上唯一的「活物」，
   反衬出其余部分的静。且长时间循环会分散对标题的注意（reduced-motion 已适配 ✓）。

### 会话视图
5. **消息密度与留白**：用户气泡灰底 vs AI 回复裸排的对比是好的（对话双方身份清晰）；
   思考段折叠「已思考」是好设计。但 AI 回复的**段落宽度没有上限约束时**
   长段落扫读吃力（截图里尚可，需核验长文本）。
6. **widget 卡是隐藏的王牌**：内嵌 Chart.js 饼图是同类产品没有的差异化能力，
   但卡片的呈现（标题+图+下载键）默认收敛得比较平，缺少「这是一件成品」的仪式感。
7. **timeline 轴**：「更新时间」竖轴信息密度低、占左侧一条；工具调用的展开/收起
   交互好，但视觉重量与正文几乎相同，扫读时无法一眼定位「哪一轮产出了什么」。

### 侧栏
8. **「即将开放」四连灰**：已成分组（好），但四个条目视觉上与可用导航同权重，
   只是颜色略淡。用户感受：「这软件一半功能没做完」（实际上那是远期规划）。
   建议进一步压缩视觉重量（更小字号/更紧的行高/或合并为一行「更多能力规划中」）。
9. **底部「本地模式」徽章**：这是**信任锚点**（本地优先的卖点）却做得最小。
   对看重隐私的用户，这是第一屏最该被看到的信息之一。

### 横向对比结论（调研融合）
| 同类亮点 | ZeroWork 现状 | 融合判断 |
| --- | --- | --- |
| Claude Desktop：多会话侧栏按项目分组 | 会话在二级导航 | **高价值**：首页加「最近会话」一键续聊（高频路径缩短一跳） |
| Claude Desktop：对话+artifact 分屏 | 产物面板已有（右侧）| 已具备，可在会话内做「产物变化时轻提示」 |
| Cherry Studio：极简/专注模式呼声高 | 无 | **中价值**：折叠侧栏的专注态 |
| Chatbox：markdown/公式渲染是卖点 | markdown 已有，公式未验 | 核验 KaTeX 是否在位，缺则补 |
| Cherry Studio：透明窗口 | 无 | 低价值，跳过（与桌面壁纸耦合，难保证品质） |

## B. 改进提案

### P0（不动布局，token 引用级，1-2 天）
- **P0-1 品牌锚点**：首页标题下方的打字机副标题末尾光标、发送键 hover 态、
  三步清单完成态的对勾，三处引入 `--brand`（现值不动，扩展使用位需按 DESIGN.md
  论证：这三处都是「产品活了/完成了」的语义，与状态点同族，不是装饰）。
  用户感受：界面有了性格。
- **P0-2 清单可点性**：三步清单项加左缘 2px 交互指示条（hover 展开）+ 整行
  `cursor: pointer` + 未完成步骤用 `--accent` 序号。已有 hover 底色，补的是
  静态可点暗示。
- **P0-3 「即将开放」减重**：四项合并为一组更小字号（--text-meta）+ 更紧行高，
  组标题改「规划中」；`--text-secondary` 保持（DESIGN.md §2.1 已论证过降两档的教训）。
- **P0-4 「本地模式」升格**：徽章从纯文字改为 状态点(已有绿点)+文字+hover tooltip
  （「数据只存在这台电脑：工作空间/会话/偏好」）。一次 hover 建立信任。

### P1（动结构，3-7 天）
- **P1-1 首页「最近会话」区**：三步清单完成（或存在历史会话）后，清单区让位给
  最近 3 条会话卡（标题/相对时间/场景徽标），点击直达。空态回落到清单。
  这是把「第二次打开」的路径从 两跳（会话→找）变一跳。
- **P1-2 专注模式**：会话视图内一键折叠侧栏（⌘. / Ctrl+.），输入卡吸底不变。
  布局用现有 grid 列收窄实现，不新造容器。
- **P1-3 widget 成品感**：产出 widget 卡加「成品」徽标（--brand 点 + 「产物」字样）
  与轻入场动效（opacity+translateY，走 --dur-base，登记进 §10.3 动画清单）。

### 不做（与纪律冲突或价值不足）
- 透明窗口（品质不可控）、多主题色（token 体系会膨胀）、消息流仿 IM 化
  （办公场景的密度优先）。

## C. 验收要点（每个提案的测试义务）
- P0 全部：浅/深双主题截图断言（套用 theme 测试模式）+ smoke 回归
- P1-1：会话存在/不存在两种首页形态的 GUI 用例 + 断言点击直达
- P1-2：快捷键折叠/展开 + 截图 + reduced-motion 不破坏
- P1-3：widget 卡渲染断言（现 widget 套件扩展）
