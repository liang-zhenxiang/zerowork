## 背景

Top 5 已修完。剩余项里，首页矮视口、统计页头部、记忆空态等会与 #397
（Composer / 统计页 / ChatView）撞车，先不做；本次只做三处不冲突、收益明确的小修：

1. **Windows 上写着「在 Finder 打开」**：项目唯一完整支持的平台是 Windows，
   设置 → 数据管理的存储位置按钮却用 macOS 专属文案；资料库同一动作已用
   「在文件夹中显示」。
2. **Hooks 设置页中间有 9 行技术散文**：设置页要能扫读；关键规则被埋没在长段落里。
3. **计划书步骤行在暗色下失去容器**：`--bg-raised` 与抽屉面 `--surface-1` 在暗色
   同为 `#0e1624`，步骤行看起来像没有背景。

## 需求

### 1. 平台中立文案

- 存储位置按钮改为「在文件夹中显示」，与资料库一致
- GUI 断言：该行文本包含「在文件夹中显示」且不含「Finder」

### 2. Hooks 规则说明折叠

- 长段落改为 `<details class="hooks-rules">`，summary 为「规则说明（放行 / 拒绝 / 超时 / 匹配 / 注入）」
- 展开后为 5 条短句：退出码 / 四类不阻断事件与会话结束 2s 预算 / 上下文注入与上限 /
  命令与匹配语法 / 生效范围
- 默认折叠；summary 有焦点环；浅/暗可读
- GUI 断言：默认 `open=false`、点击后展开

### 3. 计划书步骤容器

- `.plan-book-step` 背景由 `--bg-raised` 改为 `--surface-2`（暗色比表面亮一档）
- GUI 断言（暗色）：步骤行背景 ≠ 抽屉背景
- 浅色下仍应与抽屉面有可辨差异（surface-2 #f8fafd vs surface-1 #fff）
