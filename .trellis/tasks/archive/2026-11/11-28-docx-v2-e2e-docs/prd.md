# PRD：docx v2 端到端与文档（#501）

## 背景

v0.28 的三项能力（跨 run、批量、上下文）都有了单测与部分 e2e，但还缺「真实工具链 + 真实写回」的端到端证据，USAGE 也仍停在 v1 的范围（「跨 run 一律拒绝」）。

**依赖**：#498 / #499 / #500 均已合并。

## 目标

1. e2e：同格式跨 run 的真实工具调用 → 建议 → 接受 → 段落文本已改、其余条目与版式特征不变（运行时未就绪时只验证建议生成）。
2. e2e：批量建议只勾一条接受 → 文件里只有勾选的那处变化；未勾选的保持原样。
3. e2e：批量中第 2 条失败 → 整次不写盘、错误指明第 2 条、原文件字节不变。
4. e2e：上下文徽标的段落序号与 `inspect_docx.py` 的段落顺序一致。
5. `docs/USAGE.md` 的 docx 子段改为 v2：同格式跨 run、批量（≤50 条、逐条勾选、全有或全无）、位置上下文；明确仍不做的（结构编辑、格式不同跨 run、Word 原生修订痕迹）。
6. CHANGELOG 的 v2 条目与 USAGE 措辞一致。

## 非目标

- xlsx / pptx。
- 在 CI 上安装运行时（依赖 Python 的用例显式 SKIP，报告可见）。

## 验收

- [ ] 新增 e2e 用例本地全绿（含依赖运行时的三条）
- [ ] CI 上依赖运行时的用例显式 SKIP、不拖红其他用例
- [ ] USAGE 与 CHANGELOG 与实现一致
- [ ] `npm test`、`lint:all`、`check:unicode`
