# 会话过程可见性（issue #274）

## 背景
三轮视觉迭代后，第一次真实使用的摩擦在信息差：看不到 agent 正在读写的文件、
长会话回找结论费劲、缺轻量中断与定位手段。

## 方案（MVP，一晚能收口）
1. 活动侧栏（ActivityRail）：会话页右侧固定窄栏，列出当前轮次工具调用
   （类型图标 + 文件名/命令摘要 + 状态点），从现有渲染层事件流接只读数据。
2. 单步查看：点击侧栏条目滚动定位到对应消息块并高亮 2s。
3. 会话内搜索：⌘F 聚焦搜索框，实时高亮 + 上下跳转匹配消息。
4. 消息时间戳 hover：安静不可见，悬停显示。
5. 回到最新浮动按钮：滚离底部 > 一屏时出现，点击平滑回底。

## 非目标
不动 daemon IPC 协议；不做虚拟滚动（消息量级未到）。

## 验证
tests/e2e/session-visibility.mjs：mock 会话跑 5+ 轮工具调用，
断言侧栏条目数/定位滚动/搜索高亮/时间戳/回底按钮；每功能 ≥1 张截图。
lint:all + unit + build 全绿后开 PR。
