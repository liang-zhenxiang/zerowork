# PRD · 界面视觉升级：极光墨（Aurora Ink）

## 背景

用户对现有界面的评价是「太 low：偏灰、偏平、像模板」。这不是主观抱怨 ——
对 baseline 截图逐项核对可以定位到四个具体成因：

1. **没有饱和色锚点**：整页灰阶从 `#fff` 到 `#666`，唯一高对比元素是「日常办公」这个 tab，
   视线落在一个不重要的元素上；
2. **所有层级同一种描边**：工具胶囊、清单里的三个按钮、输入卡、案例卡全是「1px 浅灰描边 +
   大圆角 + 白底」，四类不同层级长得一样，页面只剩网格；
3. **模板节奏**：居中大标题 → 一排胶囊 → 灰清单卡 → 白输入卡 → 四张同构图案例卡；
4. **暗色更糊**：页面底、侧栏、卡片几乎同一明度（都在 `#1c1c1e` 附近）。

途中还发现一处真缺陷：设置页右上角的 `✕` 关闭键**压在「刷新模型目录」按钮上**。

## 目标

用一套**成体系的视觉语言**替换上述现象，而不是零散调色：

- 冷调画布 + 三团极光（青 / 紫 / 橙的低透明径向渐变）建立深度；
- 侧栏走雾面玻璃（`backdrop-filter`），与画布形成「一层玻璃、一层纸」的关系；
- 强调色收敛成**唯一 teal**，主行动（新建任务、发送键、选中项）只出现在它上面；
- 展示标题 46px + 负字距，给首页一个明确的第一落点；
- 首页、侧栏、设置页、**会话页**四屏同一语言（会话页是真正干活的地方，
  只改首页等于点进去就掉回旧世界）。

## 非目标

- 不改任何交互流程、不新增功能入口、不动 daemon / IPC 契约；
- 不重写 `app.js` 的结构（只在 HomeView 里插入一个 `aria-hidden` 的眉标节点）；
- 不引入新的 npm 依赖、不引入图片素材（品牌徽标是纯 CSS 的 `::before`）。

## 风险与已知取舍

- `backdrop-filter` 在旧 GPU / 远程桌面下可能退化为纯色（可接受：退化后仍是浅色面，
  不会变成刺眼亮带）；
- 视觉重心刻意只有一个（teal 主行动），其余元素主动降权 —— 这意味着页面「不热闹」，
  是设计决定不是遗漏。
