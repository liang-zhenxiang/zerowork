# 第四轮十个「一眼可见」的功能

## 背景

三轮视觉迭代后（v0.13.0 + 第三轮微交互 + 会话可见性），界面已活起来。
这轮继续填「真实使用一天就会想要」的东西。

## 期望（10 个，全部截图）

1. 消息操作栏常驻化：hover 消息出现复制/重试/分支，无需先选中
2. 快捷键速查表：⌘/ 弹出全应用快捷键面板
3. 侧栏任务分组折叠记忆：分组折叠状态跨启动记住
4. 输入框 @ 引用文件：输入 @ 弹出工作区文件选择器
5. 会话导出进度反馈：导出 Markdown 时按钮内进度
6. 模型切换器显示余额/上下文用量：当前会话 token / 上下文窗口比例
7. 首页案例卡 hover 预览：hover 时封面轻微抬起 + 显示适用场景
8. 错误消息可诊断化：会话报错时显示原因与「重试/复制错误」操作
9. 窗口标题栏显示当前任务名：一眼知道自己在哪个任务
10. 空输入框的浮动提示词：placeholder 轮播不同任务示例

## 非目标

不动 daemon 协议；不引入新依赖；不动 resources/**。

## 验证

tests/e2e/ui-round4-shots.mjs ≥10 张；lint:all + unit + build 全绿。
