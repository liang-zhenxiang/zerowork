# ⌘K 全局搜索：把「会话检索」升级为跨域统一搜索

## 背景

ZeroWork 已有分散的搜索入口：
- ⌘K 命令面板：只搜命令（打开设置/换主题…），不搜内容
- 「会话检索」页：搜会话正文（searchSessions IPC，单测+e2e 7/7）
- 设置搜索：上一轮做了又移除了（#281，「低频且分散注意力」）
- 文件历史页：按文件看 agent 改动，无文本搜索

用户心智是「想找东西就 ⌘K」——但 ⌘K 找不到会话内容、找不到文件，
得记住三个入口分别在哪。这是竞品（Raycast / Linear / Slack）早就统一掉的事。

## 期望（本轮范围）

1. ⌘K 命令面板输入文字时，除命令外**就地混排**三类结果：
   - 会话（复用 searchSessions IPC，取 top 5，显示命中摘要，点击跳回原消息）
   - 任务（taskList 本地过滤标题）
   - 文件（workspace 下文件名匹配，复用现有文件枚举通道，若有）
2. 分组标签（命令/会话/任务/文件）+ 各自图标 + 键盘导航跨组移动
3. Enter 行为按类型分派：命令→run；会话→openSearchHit；任务→resumeTask；文件→打开文件历史定位
4. 结果空态给出下一个入口建议（「去会话检索页看全部 N 条命中」）
5. 不改 searchSessions 的 IPC 协议；面板渲染层做融合
6. 检索为空/极短（<2 字符）时只出命令，不打 IPC（防抖 200ms）

## 非目标

- 不做全文文件内容索引（只搜文件名）
- 不改「会话检索」独立页（保留作为深搜入口）

## 验收

- e2e：command-palette.mjs 扩展用例——预置会话文件（同 session-search.mjs 手法），
  ⌘K 输入关键词 → 断言混排分组出现、键盘导航跨组、Enter 跳回原消息带 entry-flash
- 截图 ≥2 张（混排结果、空态建议）真实启动验证
- lint:all / npm test / npm run build 全绿
