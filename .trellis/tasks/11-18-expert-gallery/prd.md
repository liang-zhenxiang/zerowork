# PRD：能力库画廊（#421）

## 背景

#420 让能力可以打包、导入、导出；但专家页仍是「一屏卡片 + 一排标签」：
看不出哪些是内置、哪些是自己装的能力包，也看不到包里有什么技能；导入只能点按钮选文件。
能力包多起来之后，「发现 → 试用 → 管理」没有一条顺手的路径。

## 目标

1. **来源可辨**：全部 / 内置 / 我的 / 能力包四档筛选，带计数；卡片显示来源与版本。
2. **可排序**：默认 / 名称 / 最近安装（能力包按安装时间）。
3. **技能可见**：详情里列出该专家包含的技能（名称 + 描述）与成员数。
4. **导入更顺**：把 `.zwpack` 拖到专家页即可预览。
5. **视觉成画廊**：卡片有确定性的封面色条，亮暗一致，保持现有 `.ex-*` 语汇。

## 非目标

- **停用 / 恢复专家** —— 涉及跨会话语义（当前选中、子代理），单独记录在 #426。
- 远程市场 / 在线安装 —— 本地优先，不做。
- 重写专家选择器、会话内专家切换 UI。

## 约束

- 不改变专家加载与选择语义；`listExperts` 只增字段，不改既有字段。
- 不新增依赖；拖拽路径必须来自 preload 的 `getFilePath` 或 `text/uri-list`，渲染层不猜路径。
- 视觉只用既有 Token 与 `--cat-1..6`；不新增字号档；动效走 `--ease-standard`。
- 空态、加载态、错误态、筛选无结果都要有可读呈现。

## 验收标准

- [ ] 来源筛选四档可用，计数与列表一致；与标签筛选、搜索可叠加。
- [ ] 排序三档可用，「最近安装」对能力包按 `installedAt` 降序，内置/我的按名称兜底。
- [ ] 卡片显示来源徽标（能力包带版本）、技能数；封面色条在亮暗两套都成立且不喧宾夺主。
- [ ] 详情显示技能列表（名称 + 描述，缺描述时留白不伪造）、成员数与来源（能力包带版本与安装时间）。
- [ ] 拖拽 `.zwpack` 到专家页出现拖放提示，松开后打开能力包预览；非 `.zwpack` 给出可读提示。
- [ ] GUI 截图：能力库亮/暗、筛选后、详情技能、拖放提示。
- [ ] 单测覆盖筛选/排序/计数/拖拽路径解析（含 Windows 路径与 URL 编码）。
- [ ] 既有 `gui-pack`、`gui-smoke`、`ipc-functional`、`bridge-rest` 不回归。
- [ ] `CHANGELOG` 记「新增」；`docs/USAGE.md` 的能力库小节更新。
